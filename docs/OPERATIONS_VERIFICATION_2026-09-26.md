## Десять вопросов

Набор в `tests/fixtures/acceptance-prompts.json`: арифметика, рецепт, многоязычный текст, JSON, естественные науки, история, программирование, сеть, планирование и логика. Локальная проверка политики вернула желаемое число нод `[1,1,1,1,1,2,2,3,1,3]`; это **не** фактический выбор нод хабом. Python задания дали соответственно `250`, `375 и 180`, `4 слова`, `ключи warehouse/boxes`. Для шести AI вопросов ответы физической LM Studio отсутствуют. Скрипт `scripts/ten_prompt_live_test.mjs` отправит задания и сохранит фактические результаты после настройки `CITADEL_ARCHITECT_TOKEN` и доступа к хабу; без токена он создал только записи `blocked` и ничего не отправлял.

## Развёртывание D1 обзора

Создайте Cloudflare API token с правами чтения D1 и Analytics для нужного аккаунта. Установите в Worker секреты `D1_ANALYTICS_TOKEN`, `D1_ANALYTICS_ACCOUNT_ID`, `D1_ANALYTICS_DATABASE_ID` и `D1_USAGE_PLAN` через `wrangler secret put`. ID базы в `wrangler.jsonc`: `8e7855f0-905d-4ca4-96e7-4df015ada1c7`. Выберите реальный тариф; для неизвестного тарифа интерфейс показывает абсолютные значения без доли лимита. Секреты Worker должны пережить последующие деплои. Эндпоинт `GET /api/v1/architect/d1-usage` требует авторизацию Architect. Метрики Cloudflare могут поступать с задержкой.
